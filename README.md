# Circular Particles

A 3D sphere particle system visualization built with React and Canvas.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser to the URL shown in the terminal (usually `http://localhost:5173`)

## Features

- Interactive 3D particle sphere with customizable parameters
- Background particle effects
- Motion blur/echo effects
- Real-time parameter adjustment controls
- Export configuration to clipboard
